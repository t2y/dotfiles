# CLAUDE.md (user)

- Go のコードを書く・リネームする・レビューするときは、`go-coding-conventions` skill を読んでから着手する。
- Go のテストを書く・ケースを足す・レビューするときは、`go-test-conventions` skill も読んでから着手する。
- 日本語で markdown を書くときは `japanese-tech-writing` skill の文章規範を適用する。README、設計ドキュメント、設計プラン、GitLab / GitHub の issue・merge request・pull request の説明やコメントを含む。
- 設計プランは repo の `docs/` ではなく `~/.claude/plans/<slug>.md` に置き、設計が変われば同じファイルを更新する。
